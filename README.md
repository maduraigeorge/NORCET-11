# NORCET-11 Placement Desk

Dashboard for AIIMS NORCET-11 Stage-II results: look up a roll number, see the chance of a seat and the safest institutes to list.

Live page: https://maduraigeorge.github.io/NORCET-11/

## Update the data

Replace the files in `data/` (keep the column names), commit and push. Open pages re-check every 30 seconds, and GitHub Pages usually serves the new files within a few minutes.

- `data/norcet11_stage2_qualified.csv`: roll_no, category, pwbd, gender, percentage, rank
- `data/norcet11_vacancies_detailed_updated.csv`: seats by institute, quota and gender

Estimates only. Seat numbers are provisional until the AIIMS seat position is published (30 Oct 2026).
